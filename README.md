# ⚔️ Bleach 20th Anniversary - Projeto Mugetsu

Um tributo visual aos 20 anos de Bleach, focado na jornada de Ichigo Kurosaki. Este projeto demonstra técnicas avançadas de front-end para criar uma experiência imersiva.

## 🌟 Destaques do Projeto
* **Hero Section com Vídeo:** Uso de background em vídeo com sobreposição de gradiente para um visual cinematográfico.
* **Layout Responsivo:** Implementação de **Flexbox** para alinhar textos e imagens lateralmente em telas grandes e empilhados em dispositivos móveis.
* **Mural de Transformações:** Galeria dinâmica utilizando **CSS Grid** com a função `auto-fit` para organização automática dos cards.
* **Efeitos de Interação:** Animações de `transform` e `scale` ao passar o mouse (hover) sobre os elementos da galeria.

## 🛠️ Tecnologias e Conceitos
* **HTML5 Semântico:** Organização clara das seções do site.
* **CSS Custom Properties:** Uso de variáveis (`:root`) para facilitar a manutenção de cores e temas.
* **Typography:** Integração com Google Fonts (Source Code Pro).
* **Design All Black:** Estética inspirada no visual "Mugetsu" do protagonista.
